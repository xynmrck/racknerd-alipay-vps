## 续费价格：还是那个价，但要手动付

这是 RackNerd 最被中文用户称道的政策，官网原话是这些特价套餐「lifetime recurring」，只要你还想继续用，续费价格和首购一样，不会第二年偷偷涨。

实际操作有个细节很多人不知道：**默认没有自动扣款**。到期前 14 天系统会自动生成续费账单并发邮件提醒，你需要登录客户区，进 Services 页面选中对应的 VPS，点左侧 Actions 里的「Generate Renewal Invoice」，账单金额就按你当初的购买价出，支付宝再付一次即可。想省事的可以单独开启 Auto-Recharge，默认是关闭的。到期后还有几天到一周的宽限期，期间服务暂停但数据保留，超过期限才会被回收。

也就是说，支付宝不只首购能用，每年续费继续用同一方式付款就行，全程不需要外币卡。
